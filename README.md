# Earth 256D: Android Beta

Download the latest **Earth 256D Android APK**, browse release notes, and help test a messaging app where each dimension changes the rules of conversation.

Travel together, send a Tether request, or watch your words fade in Decay. Ordinary messaging was apparently insufficient. We added physics.

## Download and install

Open [Releases](<https://github.com/atlonglastkibet/earth256d-downloads/releases>), download the latest APK, and install it on your Android device. If Android asks, allow installation from your browser or file manager.

This repository hosts **Android beta downloads and release notes**. Learn more about Earth 256D at [earth256d.com](<https://earth256d.com>).

## Welcome to the beta

Expect new features, frequent refinements, and the occasional bug with unusually strong opinions about how things should work.

Found something broken? Tell us what happened, your app version, and how to reproduce it. “It did a weird thing” is spiritually valid, but steps help.

Messages disappearing in Decay: expected.  
Request cards refusing to open: less expected.  
Both are excellent reminders to read the release notes.
